# Parfumerie Démo

Static demo of a perfume shop web app for Algeria: online shop + admin (orders, stock, cash register, customers, loyalty, profit), in French and Arabic. Everything runs in the visitor's browser with fictional data; there is no server.

- Open `index.html` through any static host (Vercel, Netlify, Cloudflare Pages, GitHub Pages). No build step: this repository is the built site.
- Vercel: import the repository, framework preset **Other**, leave the build command empty and the output directory at the root.
- A guided tour (bottom button) walks through the shop and the admin. Sign-in needs no password.
